# Vedant Desai, portfolio site

Static site. Plain HTML, CSS and JS, with GSAP for motion and Lenis for smooth scroll.
No framework and no runtime dependencies from other domains: fonts and libraries are
self-hosted so the Content Security Policy can stay at `'self'`.

Specs, copy and the build plan are in `docs/` (start with `docs/01-brief.md`).

## Commands

```
npm run build    # regenerates the tower drawing, then copies src/ to dist/
npm run serve    # serves dist/ locally
npm run globe    # only when changing the globe: run npm install first
```

Node 18 or newer. `dist/` is what gets deployed.

## Structure

```
src/
  index.html            page markup; <!-- @include --> pulls files from partials/
  partials/tower.svg    hero elevation, generated by tools/tower.mjs (don't edit by hand)
  assets/css/main.css   all styles, tokens at the top
  assets/js/boot.js     tiny, loads first; switches to a static page if motion can't run
  assets/js/main.js     loader, hero intro, stats counter, parallax, cursor readout
  assets/vendor/        gsap 3.15.0 (+ ScrollTrigger, SplitText, DrawSVG, ScrambleText), lenis 1.3.26
  assets/fonts/         Big Shoulders, Barlow, IBM Plex Mono (woff2, latin)
  assets/img/           photos
  assets/docs/          public CV
  _headers              security and cache headers for Netlify
  vercel.json           same headers for Vercel
tools/
  tower.mjs             draws the tower (floors, windows, columns, dimension line)
  build.mjs             src -> dist
```

## Motion

The hero runs once after the loader: set-out line, piles and grid bubbles, then the frame
and floors climb together, the dimension line counts the height, the crown goes on and a
few windows light up. The name rises letter by letter and Vedant comes up from the base
line as the tower tops out.

Everything is skipped when the visitor has reduced motion turned on, and the page shows
complete if JavaScript or the vendor files fail to load (`boot.js` gives it 4 seconds).

To change the building, edit the `blocks` list in `tools/tower.mjs` and run the build.
Each floor is its own `<g class="t-floor">`, so the animation picks up new floors without
changes to `main.js`.

## Security

- CSP allows only same-origin scripts, styles, fonts and images. No inline scripts or
  inline style attributes in the markup, so keep it that way when adding sections.
- HSTS, nosniff, frame denial, strict referrer policy, permissions locked down.
- No analytics, trackers or third-party embeds.
- The contact form (later milestone) will post to a serverless function with a honeypot
  and rate limit; the email address won't appear in the page source.
